# ADR-0002: New Nova code is licensed MPL-2.0

- **Status:** accepted (pending owner confirmation — see `TASKS.md` open decisions)
- **Date:** 2026-09-07
- **TRD refs:** §2

## Context

LibreOffice is MPL-2.0 / LGPL-3.0-or-later. Nova links against it and adds new
modules, a design system, a reference server, and a plugin SDK. We need an
outbound license that is compatible, keeps improvements open (project goal), and
does not force the whole program or third-party plugins into strong copyleft.

## Decision

New Nova code: **MPL-2.0**. Documentation: **CC-BY-4.0** (dual with MPL). Brand
assets: all-rights-reserved (trademark). SDK/server may relax to Apache-2.0 by a
later ADR if a linking-clarity need arises.

## Alternatives considered

- **LGPL-3.0-or-later** (match half of upstream). Viable; MPL chosen for
  simpler file-level scope and better fit with a permissively-licensed server
  and plugins.
- **Apache-2.0** everywhere. Rejected as default: gives up the file-level
  copyleft that keeps Nova improvements open.
- **GPL-3.0.** Rejected: would force plugins and combined works copyleft,
  conflicts with the extensibility goal (§36) and with some permissive deps.

## Consequences

- +: Compatible with MPL/LGPL upstream; two-way contribution with the LO
  community; plugins may be proprietary (§36).
- −: Mixed-license repo (MPL + upstream LGPL/MPL) — SPDX headers + notices
  discipline required ([`../licensing.md`](../licensing.md)).
- Follow-ups: SPDX check (`scripts/check-spdx.mjs`, done); `THIRD_PARTY_NOTICES`
  generator (TODO); legal review before first binary.
